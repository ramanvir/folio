# Mull Reader — https://mullreader.com
#
# Mull Reader is a static site with no backend, no accounts, and no stored
# user data. The realistic attack surface is the rendering path: markdown is
# parsed with marked and sanitised with DOMPurify before it reaches the DOM,
# so a sanitiser bypass that lands script execution is the finding that
# matters most. Please report it rather than posting it publicly.
